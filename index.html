CSV format

One filename per line. Optional header row (auto-detected). Lines starting with # are ignored. Matching is case-insensitive.

filename

Host on GitHub Pages (free, no build needed)

  1. Create a free account at github.com if you don't have one
  2. Click New repository — set it to Public, name it e.g. mortgage-checklist
  3. Upload this index.html file to the repository root (drag & drop on the repo page, or use Git)
  4. Go to Settings → Pages in your repository
  5. Under Source, choose Deploy from a branch, select branch main and folder / (root), then click Save
  6. Wait ~1 minute — your site will be live at https://<username>.github.io/mortgage-checklist/
  7. Share that URL — anyone can open it in a browser and upload a CSV to update the checklist
